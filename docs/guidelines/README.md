# 지침 원문 보관 폴더

국가기록원 지침 원문(PDF, 한글파일, 텍스트 등)을 참고용으로 보관하는 곳입니다.
**앱이 이 폴더를 읽어서 자동으로 문제를 만들어주지는 않습니다.** 문제는 앱의
관리(문제 관리) 화면에서 원문을 보면서 직접 입력해야 합니다.

## 폴더 구성 규칙

앱에서 만든 카테고리 이름과 같은 이름으로 하위 폴더를 만들면, 나중에
"이 카테고리 문제가 어느 지침에서 나왔는지" 찾기 쉬워집니다.

```
docs/guidelines/
  기록물관리 지침/
    원문.pdf
    (필요하면 관련 별표·서식 등도 같이)
  처리과 기록관리 표준/
    원문.hwp
```

## 사용 순서

1. 국가기록원에서 받은 지침 파일을 지침명과 같은 이름의 하위 폴더에 넣습니다.
2. 앱(관리 화면)에서 같은 이름으로 카테고리를 만듭니다.
3. 원문을 읽으면서 OX/객관식/빈칸채우기 문제를 앱에 직접 입력합니다.

## 참고

- 한글(.hwp) 파일은 GitHub에서 미리보기가 안 될 수 있어요. 필요하면 PDF로 변환해서
  같이 넣어두면 웹에서 바로 확인하기 편합니다.
- 저장소가 비공개(private)인지 확인하고 올리세요. 지침이 내부용이라면 공개 저장소에는
  올리지 않는 게 안전합니다.
