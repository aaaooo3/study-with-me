# 지침 원문 보관 폴더

국가기록원 지침 원문(PDF 등)을 보관하는 곳입니다. 여기 넣은 PDF는
`node scripts/pdf-to-text.mjs`로 텍스트 변환해서 `public/guideline-texts/`에
저장되고, 앱의 "지침에서 자동 생성" 기능이 그 텍스트를 읽어 OX/빈칸채우기
문제 초안을 규칙 기반으로 만들어줍니다 (AI API 호출 없음). 자동 생성은
초안일 뿐이라 앱에서 검토 후 선택적으로 추가해야 합니다. 물론 원문을 직접
읽으면서 앱에 문제를 손으로 입력해도 됩니다.

## 새 PDF를 추가했을 때

```bash
node scripts/pdf-to-text.mjs
```

이 스크립트를 실행하면 `docs/guidelines/`의 모든 PDF를 다시 스캔해서
`public/guideline-texts/*.md`와 `index.json`을 갱신합니다. 실행 후 결과를
커밋해야 앱에 반영됩니다.

## 참고

- 파일명이 `NAK <번호> <연도>(v<버전>) <제목>.pdf` 형식이면 변환 스크립트가
  번호/연도/버전/제목을 자동으로 인식합니다. 다른 형식이면 파일명 전체를
  제목으로 사용합니다.
- 한글(.hwp) 파일은 변환 스크립트가 처리하지 못합니다. PDF로 변환해서 올려주세요.
- 저장소가 비공개(private)인지 확인하고 올리세요. 지침이 내부용이라면 공개 저장소에는
  올리지 않는 게 안전합니다.
